# Rullo

App web per allenarsi con un rullo interattivo Bluetooth (provata con Wahoo Kickr Core):
pedalata libera, allenamenti strutturati (anche .zwo/.erg/.mrc), percorsi GPX con pendenze
reali, storico e file .FIT da caricare su Garmin Connect / Strava.

Si usa da Chrome su Android o su PC con Bluetooth. Menu ⋮ → "Installa app" per averla a
schermo intero. I dati restano solo nel dispositivo di chi la usa: nessun account, nessun server.
